# 卡牌更新暂停与 3D 功能回归（2026-10-04）

当前版本以 3D 场地功能完整性为优先。卡牌内容更新保持关闭，本次没有打包、上传或发布客户端，也没有修改线上静态站点或内容频道。

`project.godot` 显式设置 `ptcgdap/card_content/enabled=false`。首页不创建右上角卡牌更新按钮或弹窗；自动和手动更新入口均不请求网络；启动引导不读取、挂载、激活或确认以前下载的更新包。已有更新文件和玩家存档保留，当前进程使用 bundled 内容快照。普通应用版本更新保留。

停用开关由客户端构建决定，玩家的自动下载偏好不能重新开启它。`ContentBootstrap` 保持第一个 autoload，但在关闭状态下立即返回；`ContentUpdater` 同时在初始化、检查、下载和底层请求处拦截，避免只有按钮隐藏、后台仍更新的问题。

新增 `CardContentDisabled` 的四项测试先在未修复版本全部失败，加入停用逻辑后全部通过。覆盖默认关闭、真实首页没有入口、直接调用也不会联网、已有 active/pending/trial 状态不被改写。功能开启时的开发测试显式设置开关，并在结束时恢复。

本地验收结果：

- 25 组 Godot 功能回归：336/336 通过，0 跳过。包含卡图回退、内容更新停用、卡牌数据库、内置牌组、对战设置、3D 演出与交互。
- Python 导出、发布工具、资源引用和种子版本检查：18 项及 19 个子测试通过。
- Windows OpenGL 真实渲染界面：11/11 场景最终通过。覆盖开局、重抽、搜牌、领奖与弹窗、换位、场地详情、换手中调整窗口、基础输入、搜牌/换手演出、八备战和两张奖赏。
- 3 个独立渲染探针全部通过：实际对局开局/选卡/结束回合/AI、手机布局反馈、四尺寸触摸。触摸尺寸为 720×1280、1280×720、390×844、768×1024；手机反馈另外覆盖 1080×1920、连续附能、三张奖赏及一至六张奖赏演出。
- 实际渲染首页截图已检查，右上角没有卡牌更新按钮。

回归中同步了过时的验收预期，未因此改变 3D 业务行为：

- 连续精神拥抱检查两次真实附能、40 点累计代价和第二次短提示，保留首次完整模型演出。
- 被移除的装饰蕨叶不再计作可见桌面；改为核对七个完整桌面材质、运行时材质存在及蕨叶确实隐藏。
- 领奖和奇树换手等待真实演出队列完成，最多 8 秒，之后仍严格核对卡牌数量、选择窗口及下一回合。不会跳过动画或直接调用提交来让界面测试通过。
- 六张奖赏展开后，先验证被覆盖战斗位不能被右键穿透，再通过可见备战卡检查详情和领奖弹窗互斥。
- 搜牌窗口同时检查逻辑画布及转换后的物理屏幕边界，保留四个实际窗口尺寸，不再把 900 单位逻辑短边误当物理像素。

一次搜牌已选卡移除的自动点击失败尚未稳定复现。保留该失败记录，加入选择结果诊断后，完整场景一次诊断运行及随后连续两次复测均通过；不将其描述为已定位的业务缺陷。窗口缩放时的手牌投影警告，以及手机探针退出时的 ObjectDB 清理警告仍保留在原日志中，未通过屏蔽日志消除。

证据保存在工作区 `.tmp/content_disabled/`：`validation.json` 汇总最终结果、所有界面尝试及当前业务文件摘要；`functional-merged.json` 保留每组功能回归的失败和重跑记录；`arena-probes/run-20261004-233424/report.json` 保存探针结果；`arena-search-repeat/run-20261004-233709-533900/report.html` 保存两次追加复测。原失败报告没有覆盖或删除。

这些是 Windows 本地源码和 Viewport 触摸验收，不代表新 APK、安卓实机、Mac、浏览器或性能门槛已经通过。继续保留关闭状态；未来重新启用需要单独完成冻结客户端升级、旧缓存、断网恢复及各目标平台验收，再作发布决定。回退验收脚本不应把功能开关改回开启。
