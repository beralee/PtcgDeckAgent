# 有性格的 AI 陪练对手（文字首版）

2026-09-29。用户将方向从旁观比赛解说调整为「对手本人开口说话」。实时入口已切换，旧解说模块仅保留供已有视频和测试复现。

后续已扩展为[十二种心态与表情体系](OPPONENT-EMOTIONS-2026-09-29.md)：台词模板按十五个事件/心态组合准备，心态标签、表情与历史使用同一 ID。本文的九类模板描述保留首版背景，以后续说明为准。

## 使用体验

对战设置开启「AI 对手互动」，沿用设置页面已有的 `AI 性格`。默认关闭，仅真实 3D 的普通 AI / 作者策略 AI 对战创建实例；2D、双人、录像回看和 headless 不创建。3D 的现有平台开放范围未改变，本轮没有开放 Android 3D。

首版为文字气泡：角色说自己的行动，结合战况表达得意、着急、认真或认输。内置逗比、冷静、中二三类本地风格；自由输入的完整性格传给模型，离线时按关键词选最近的一类。没有改动策略、合法动作或对手强度。

| 时机 | 根据 | 例子 |
| --- | --- | --- |
| 开场 | 双方公开开局 | 我先坐直，今天争取少下一点臭棋。 |
| 喊招 | 自己已经提交的 ATTACK | 该我出招了，幻影潜袭！先让我帅一下。 |
| 主力登场 | 自己实际 EVOLVE 至 ex / VSTAR / VMAX，同名每局一次 | 就决定是你了，喷火龙ex！我的王牌，登场！ |
| 受阻 | 开局两回合之后，一回合无攻击、进化、下基础或附能 | 卡住了卡住了……我先过，别笑太大声。 |
| 重新进攻 | 上次受阻后实际宣布攻击 | 我终于能出招啦！幻影潜袭！憋坏我了。 |
| 连续取奖 | 两次稳定公开局面间自己的奖赏实际减少至少两张 | 2张奖赏到手！今天先准我得意一下。 |
| 丢奖 | 自己被取走奖赏的实际计数变化 | 这下我得稳住了，继续战斗！ |
| 胜负 | 已确认 winner | 这局我输了，嘴硬不了一点。 |

「出牌前」指动作已提交、动画尚未播放的展示时机；不预测策略未来想选的动作，也不阻塞游戏等待模型。受阻是角色对公开回合的情绪反应，不能证明无合法动作或手牌卡死。连取奖是两次稳定快照之间的实际差值，不推断单次招式必定击倒几只。

## 模型怎样参与

保留已有 112 份内置卡组、49 份机制档案。开局前读取档案，按公开印刷识别已知组件，把双方的启动、进攻、取奖、续航与风险知识提供给模型；仍不确定未公开的完整牌表，不发送双方手牌、牌库顺序、奖赏内容、RNG 或私有录像。

模型提前生成九类事件的短台词模板，每类两句。招式、宝可梦名和实际取奖数由本地在真实事件发生时填入 `{subject}` / `{prizes}`。模型响应只更新台词库，不直接弹出一条可能已经过时的解说。未知槽位、格式错误、明显隐藏信息和部分提前战果表述被拒绝，继续用本地台词。

这是一版「事件驱动 + 模型塑造性格」的混合实现，并非每走一步都问大模型，也还没有跨局记忆或玩家聊天。内容规则检查不能证明任意模型输出在语义上完全正确，线上模型质量尚未实测。

每局最多 3 次准备请求，间隔至少 30 秒，公开组件无变化时复用；连续两次失败后停止请求。发送前按 UTF-8 字节数加输出上限保守预留，共 45,000 tokens 预算，返回供应商 usage 后校正。未配置 Key 时完全本地。实际费用取决于供应商，不在本轮测试中验证。

发言限每回合三句，普通句间隔 5.5 秒，重要结果最短 2.5 秒，终局优先。只有近期已结算结果允许短暂排队，新行动立即清空待说的旧反应。气泡八秒后收声，回看保留最近 60 句；本局静音取消本实例请求并恢复场地空间。切换场景也会取消，不影响实际对手。

## 代码边界与验证

- `OpponentTalkDirector.gd`：纯公开数据产生时机、情绪和事实槽位，无策略执行权限。
- `OpponentTalkVoice.gd`：本地风格、模型协议、模板校验与事实绑定。
- `OpponentTalkSession.gd`：异步准备、预算、节流、取消、记录；不使用全局随机数。
- `OpponentTalkController.gd`：监听已提交事件，等待选择和动画结算后计算结果。
- `OpponentTalkBubble.gd`：场地上方的对手气泡，回看、静音，原生按钮和触摸桥。

复用公开投影、卡组知识和安全 DeepSeek 传输，不改变 CABT/Kaggle 策略的设备本地边界。本次达到展示功能与离线接口集成验证，不声称提高策略对齐等级或胜率。
