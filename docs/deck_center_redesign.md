# 卡组中心 UI 升级

日期：2026-09-27。按已确认的独立设计实现，范围为 Godot 卡组中心及其导入、查看、分享流程。按后续要求，编辑器已完全恢复到本轮升级之前的实现。

## 交互与布局

- 发现位于首屏头部，始终在“我的卡组”之前。每 8 秒以 0.46 秒的左右滑动动画切换精选推荐，提供上一套、下一套、暂停/播放；鼠标悬停、输入、打开详情或弹窗、导入等工作期间暂停。推荐内容使用现有缓存；当前海报沿用原有牌表读取、图片生成和磁盘缓存。支持左右拖动/滑动、渐变背景、进度提示和点击海报放大；切换中保留进出两张画面，限制连点，结束后清理旧画面。横竖屏均呈现完整海报。
- Windows 与浏览器取消右侧预览，网格使用完整宽度并按可用宽度排列 2–5 列。点击卡组图片或信息区域直接打开完整卡组，编辑和更多按钮保持独立；手机竖屏使用单列卡组，显式显示“编辑卡组”“更多操作”；短横屏压缩推荐与工具栏，为卡组和卡牌列表保留空间。
- 主要按钮最小触摸高度为 48 个屏幕像素，按 Godot 画布到屏幕的比例缩放。更多菜单、删除确认、文章、新建、分享等沿用统一主题；2026-09-28 已按用户要求从深色绿色调整为蓝色赛博风，见下方配色升级记录。
- 搜索支持卡组名及卡牌名，提供最近编辑和名称排序；具体印刷版本仍使用系列编号和卡号区分。
- 卡组详情按宝可梦、训练家、能量分组，点击卡牌可查看全部特性、招式、费用及规则。竖屏上下排列卡图与文字，横屏并排，长文本可滚动。
- 不增加草稿、收藏功能。编辑器保留原来的卡牌网格、逐张替换、搜索、AI 探讨、保存与返回流程；没有遗留本轮数量编辑、撤销/重做或新布局代码。
- 导入解析完成后先展示确认预览，确认才写入本机；失败可重试。保留原有链接、图片与剪贴板导入入口。
- 分享支持横版总览、竖版分享两种版式和生成结果预览。继续使用现有海报生成与保存适配器。
- 删除、重命名、图片同步及 AI 探讨仍连接原有业务逻辑。编辑器恢复后，浏览器竖屏进入编辑器前也恢复原来的横屏提示。

## 2026-09-27 桌面无滚轮操作兼容

最早责任层是 `DeckCenterTheme.scroll()`：新版中心把所有平台都设置为隐藏滚动条，且隐藏滚动条不接收鼠标输入。桌面鼠标不能通过触屏拖动桥操作这些区域。

- Windows、macOS 和桌面浏览器统一使用按内容溢出显示的原生滚动条，支持点击轨道翻页、拖动滑块；缩窄桌面窗口不会切换为隐藏滚动条。
- 滚动条最小宽度为 22 屏幕像素，滑块最小长度为 48 屏幕像素，随项目画布缩放重新换算。悬停、按下和键盘焦点都有可见反馈。
- 滚动区域和滚动条支持 Tab 聚焦后使用 Page Up / Page Down、Home / End；嵌套预览只滚动当前区域，文字输入保留原有编辑按键。
- 卡组列表、完整卡组、卡牌规则、推荐文章、导入表单及预览、新建/分享等共用弹窗自动继承同一策略。手机仍使用隐藏滚动条和触摸滑动；无溢出的区域不显示多余滚动条。
- 主要实现位于中心共用主题。合并验证中另为 `DeckCenterView` 动态创建的工作区补上场景 owner，防止触摸整页滚动迁移节点时丢失 `%DeckList`、搜索框等原有绑定；新增用例先失败、再通过。保留工作区并行进行的触摸布局改动。达到的是本地 UI 交互回归层级，不新增策略对齐或发布声明。

新增回归先在修复前复现：轨道点击、滑块拖动不产生滚动，中心/详情/导入的滚动条全部拒绝鼠标输入。证据在 `.tmp/deck-center-desktop-scroll/red/`。随后通过原生 Godot 输入事件验证点击、拖动、键盘翻页、输入框保护、嵌套隔离、桌面窄窗口和手机拖动；浏览器用真实鼠标和键盘操作中心及详情，并复查触摸横竖屏。

Godot 的滑块最小长度取自 StyleBox 最小尺寸，因此这里调整实际 StyleBox 和缩放后的尺寸，而非依赖未生效的 `minimum_grab_size` 常量。参见 [Godot 4.6 ScrollBar 实现](https://github.com/godotengine/godot/blob/4.6/scene/gui/scroll_bar.cpp#L443)。

回退本兼容修复时，仅恢复 `DeckCenterTheme.gd` 中的滚动函数并删除新增辅助函数、对应中心/浏览器用例和本节说明。任务开始时的这四个文件备份在 `.tmp/deck-center-desktop-scroll/before/`；保留此前的卡组中心升级和所有其他工作区改动。无数据迁移。macOS 原生机器尚未验证。

## 2026-09-28 安卓滚动、阅读与触摸隔离
