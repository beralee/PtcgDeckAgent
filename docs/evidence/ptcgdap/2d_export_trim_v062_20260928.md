## 补测发现的触摸问题

Android 正式包补测中，竖屏固定底栏的“开始对战”被背后的音量滑块抢走触摸。新增完整场景回归先失败：按钮触发 0 次，音量从 20 变为 46。修复 `BattleSetup._input` 的分发顺序，使固定底栏在滚动内容之前、模态弹层之后处理输入。修复后按钮只触发一次，音量不变。

同一个最终 APK 在 1080×2400 模拟器用真实点击进入对战、选择出战宝可梦、完成备战选择并进入 T1；截图可见 2D 场地与卡面，日志无脚本错误、崩溃或缺失资源。首轮安装后 Google “Checking info…” 系统页面抢占前台；退出该系统页后复验同一个已安装 APK 通过，保留失败记录。模拟器不等同物理 ARM 真机。
