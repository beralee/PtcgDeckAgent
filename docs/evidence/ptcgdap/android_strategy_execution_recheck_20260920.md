# Android 开发者策略执行复查（2026-09-20）

本次模拟器测试中，开发者策略正常执行，没有发现 Android 特有的选招退化、静默切换普通 AI、策略异常或超时降级。结论限定于下面的精确包、开局与模拟器；不能据此断言任意手机、任意策略或所有局面都没有问题。

所有对局正常终局。策略错误、非法输出、同窗口异常回退、经典 AI 回退、引擎拒绝、过期线程结果和线程启动失败均为零。每端、每次运行的 12 项启动检查均通过；没有脚本错误、原生崩溃或 resources-in-use 退出错误。日志仍有 Godot 的 ObjectDB 退出警告，不能写成资源生命周期完全无警告。

e719 0.3.0 的 359 次调用全部成功，覆盖 MAIN、检索、能量来源/目标分配、攻击目标、换上、进化与开局等窗口。77 个包内规则 ID 被命中，已选择动作中出现 281 次包内规则命中，包括派帕展开、宝芬检索、长毛巨魔攻击和愿增猿特性；不是仅显示包名。Android 决策耗时中位数 20.692 ms、P95 57.705 ms、最大 145.504 ms；Windows 分别为 18.962 / 52.859 / 122.565 ms。该模拟器运行在高性能 PC 上，这不是手机性能保证。

0.3.0 和 0.4.0 的 deck/policy 文件逐字节相同，仅 `strategy_package.json`、签名和文件清单不同。因此它们验证了两个包身份，不能当成两种独立算法，也不能认为版本号增加就增强了策略。

固定输出模型在每端实际执行 **217 次本地 CPU 推理**，其中 **5 次改变合法选择**，没有模型超时。它刻意触发 4 次未知 UID、5 次选择数量不合法保护，两个平台完全一致；这些是精确测试样本允许的 9 次模型规则回退，不是“所有回退为零”。另外 51 次正常规则保护窗口没有调用模型。本包是原生执行及保护机制样本，不是竞争性学习策略的强度证据。

## 正常触屏界面证据

在同一个模拟器关闭 Wi-Fi 和移动数据，通过「AI 策略中心 → 已下载 → e719 0.3.0 开战」进入正常 BattleScene。人工完成玩家开局、直接结束玩家首回合，让 AI 完成 T1 和 T3，界面正常进入玩家 T4。本次手工局只验证执行链路，不评估对手强度。

只读观察器记录 **24 次异步策略调用、24 次成功、13 次引擎提交**；12 个 MAIN、8 个检索、2 个效果目标与2个开局窗口均由 `reviewed_competitive_policy_v2 / worker_v1` 处理。包哈希与模拟器原下载的 0.3.0 相同，16 个包内规则 ID 被命中。现场可见秘密箱、深钵镇、宝芬、高级球、博士的研究、部署与贴能完成。策略错误、非法输出、经典 AI 回退、同窗口回退、引擎拒绝、过期工作线程结果和启动失败均为零，耗时 12.606–42.274 ms。

`execution_location=device_local`、`remote_inference=false`、`external_process_attempts=0` 与断网观察一致。这个包是规则策略，因此 `learned_model_invoked=false` 正常；`android_ready=false`、`production_ready=false` 是验收/发布资格标记，不能用它们代替实际调用计数判定“策略没运行”。

本局有一个独立的录像取证缺口：`author_public_replay_rejected | provenance_source_unavailable`。源码显示录像初始化需要枚举原始 `.gd` 来源文件，而导出的 APK 中引擎目录没有这些原始文件；失败只退出录像协调器，后续 24 次策略调用仍成功。没有观察到 AI 看门狗超时或强制结束回合。故本局证据来自公开审计计数、既有本地日志及截图，不能声称已生成正常界面的完整公开录像。该录像问题尚未修复。

界面证据 APK 只比整局测试冻结快照多一个测试观察器，双方哈希记录在机器回执。结束后通过界面退出本次测试局，并安装同一冻结快照导出的普通 0.6.0 玩家 APK；验证不含 `assets/tests/`，正常主菜单启动、没有诊断入口日志。模拟器 Wi-Fi 和移动数据均已恢复，原下载策略保留。该 x86_64 APK 仅供模拟器，未发布。

## 修复的诊断问题

本轮没有修改策略规则、模型权重或对战选招逻辑。为了让复查可信，修复了以下取证工具回归：

1. 新语义投影加入后，开发者记录器无条件按 128/32 维投影记录旧 24/16 模型，导致输入与实际推理不符、旧检查失败。现在模型记录使用自身实际投影和 Base 允许范围，规则教师样本继续保留语义投影。相关 6 项测试通过，包含两种模型格式、教师数据、选项重排、隐藏字段和最终选择记录。
2. 导出工具假定 include filter 必须以 `data/**` 开头，Windows 新增更新脚本后漏打包测试模型；现按每个 include filter 独立加入测试数据。普通玩家导出会移除测试内容，并验证没有测试资产。
3. 当前 Android 改用 Gradle，原快照工具不包含被 Git 忽略的构建模板。现在给隔离快照安装匹配模板，补 `.gdignore` 防止生成资产被再次扫描、重复注册原生扩展，并关闭构建守护进程避免输出句柄阻止导出退出。
4. 测试专用入口增加只读界面观察器，等待策略工作线程消费完成后才读取公开审计计数，不提交选择、不改动画/调度，也不进入普通 APK。

聚焦验证另包括原生模型 4/4、异步交互与清理 3/3、报告检测器 10/10。完整导出与四组配对对局均在修复后重新执行。
