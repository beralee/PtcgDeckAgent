# 文字解说代理模拟与机制审阅

日期：2026-09-29。范围：按用户要求，由子 agent 扮演解说模型生成固定输出，不调用 DeepSeek 或任何付费 API。本文记录样本构造和人工审阅结果；不声称线上 DeepSeek 已经过质量验证，也不代表整条游戏集成链已通过测试。

## 交付与使用方式

- [固定响应集](../../../tests/fixtures/commentary_model_simulation.json)：18 个案例，包含 11 个可接受示例、3 个机械拒绝示例、4 个语义拒绝示例；另有双方赛前预研输出。
- 所有案例只有公开事实、具体印刷 UID 和合成事件 ID。不存在真实对局手牌、牌库顺序、奖赏身份或 API 凭据。
- `response` 使用约定的 `snapshot_id`、`text`、`evidence_ids`、`kind` 字段。`should_accept` 表示产品期望；它不是对现有验证器能力的断言。
- `public_context.validation=mechanical` 的案例可以自动判断。坏 JSON 案例应将 `public_context.raw_response` 送入网络内容解析器；其中 `response` 只是便于阅读的对照对象。
- `public_context.validation=semantic_review` 必须独立作为人工质量评审集。除非实现了对应的结构化语义验证，否则不能要求仅校验 JSON 与证据 ID 的验证器拒绝它们，再据此宣称已经解决幻觉。
- 本样本是作者依据公开卡文手写的模拟输出，不能被描述为模型盲测、随机采样或真实比赛录像回放。

## 预研知识需要守住的界限

本次检查发现已有卡组 `strategy` 文本含有与具体卡文不一致的历史描述。例如 [575653 卡组](../../../data/bundled_user/decks/575653.json) 和 [581056 卡组](../../../data/bundled_user/decks/581056.json) 把雷吉铎拉戈的复制写成特性、把其 VSTAR 能力写成从牌库拿能量，还把洗翠黏美龙描述成封锁特性；相应本地印刷并非这些机制。已有策略笔记不能直接成为解说的事实来源，本任务没有修改这些历史文件。

预研应分成三层：

1. 精确印刷卡文决定机制事实、条件、代价和效果范围。
2. 已审核的结构化打法说明卡组目标、资源竞争、取奖路线及风险；组合卡组保留每条主线。
3. 玩家备注与旧 `strategy` 只表示不受信的构筑意图，不能覆盖前两层，也不能作为向模型下指令的系统文本。

“事先理解卡组”与“知道当前隐藏区域”是两件事。预研可以知道一种构筑如何工作；实时解说只有在组件公开、动作完成后才能把其说成当前事实。即使某卡属于牌表，也不能自动推断它在手牌、牌库顶或某张奖赏里。

## 对当前公开投影的审阅意见

[CommentaryPublicProjector](../../../scripts/commentary/CommentaryPublicProjector.gd) 采用字段白名单，隐藏区只传计数，准备阶段双方场上身份盖住，不透传原始 action 数据与描述。这对防止抽牌名称和奖赏名称进入模型是正确方向。

仍需由根任务集成测试验证：

- `event` 对伤害、附能、取奖等动作只保留事件身份，必须与完整效果结算后的快照差异一起使用；事件 ID 合法并不证明解说中的目标、数值和因果关系正确。
- 当前投影刻意不传 `PUBLIC_REVEAL` 内容，因此无法仅据这个事件说出刚公开展示的卡。可以保持保守表达，但不能宣称所有公开检索细节均已覆盖。
- 多次复制、同名目标和跨选择窗口效果链，必须以实际完成时点与当时的公开场面为准。文字样本不能代替真实引擎与动画同步测试。
- 模型输入可用哨兵检查证明未携带隐藏信息；模型主动编造“下一张已确定”仍需风格约束、人工反例评估或更窄的输出契约。
- `GAME_OVER` 是终局依据。若要求绝不抢报，应由本地终局事实控制终局播报；自由文本的含义无法靠几个中文关键词完整识别。

## 验证记录

本子任务通过 PowerShell `ConvertFrom-Json` 解析完整固定集，并逐例检查重复 ID、正例快照匹配、正例证据白名单、`kind` 与文字长度，文档本地链接检查为零缺失。结果为 18 个案例、11 个正例、3 个机械拒绝例、4 个语义拒绝例，正文长度为 55–67 个字符，双方预研席位为 0 和 1；坏 JSON 原始内容被解析器拒绝。

未启动游戏、未执行根任务的功能套件、未调用线上模型。根任务应将自动集成结果另行记录，避免把固定代理响应通过测试误写成 DeepSeek 的实测表现。
