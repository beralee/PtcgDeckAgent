# 游戏内弹窗改造（2026-09-28）

## 问题与实现范围

卡组中心的重命名入口虽传入 `prefer_hud_dialog=true`，实际仍由竖屏条件决定是否使用游戏内控件，桌面继续创建 `AcceptDialog`。删除确认也有同样的横竖屏分支。其他编辑、讨论、查看和日志入口各自创建窗口，焦点、触摸和关闭生命周期分散。

新增 `scripts/ui/GameModalDialog.gd`，以当前游戏画布中的遮罩、面板、可滚动正文和固定操作区承载弹窗。视觉样式沿用当前 `DeckCenterTheme`。已接入：

- 卡组重命名、导入重名处理、删除、新建、分享及横屏提示。
- 编辑器未保存确认、保存校验错误、打法笔记、AI 分析选择和等待提示。
- 卡组查看、卡牌详情、AI 讨论、策略中心本地录像删除、对战更多操作和 3D 对战日志。

源码扫描 `scenes/` 与 `scripts/ui/` 不再发现 `AcceptDialog`、`ConfirmationDialog`、`PopupPanel` 创建。系统文件选择器仍承担用户选择本地文件的操作。

## 交互与生命周期

- 鼠标与滚轮保留 Godot 控件分发；触摸手势只由前景弹窗处理，原生文本输入保留编辑事件，Web 使用既有 DOM 输入桥。
- Esc 与 Android 返回关闭最上层弹窗；打开期间临时禁用自动返回退出游戏，全部关闭后恢复原设置。
- 关闭清除手势、文本输入代理、焦点和键盘，并恢复有效的原焦点。触摸生成的鼠标回声不会落到背景按钮。
- 弹窗适应横竖屏与软键盘区域，操作按钮保留在滚动内容外。长标题限两行；长正文滚动。
- 卡组输入支持提交、空名／重名校验和清除。导入重名的关闭入口会取消待导入事务。
- 延迟操作使用弱引用重新检查对象；清理时不会把新建节点裸引用送入尚未完成的树退出操作。共享滚动条延迟布局同样检查节点存活。

## 验证

初始三个聚焦用例全部失败，分别覆盖桌面重命名、桌面删除和编辑器提示仍为窗口节点。最终 11 个相关 suite 分批复验共 **427/427** 通过，汇总与具体日志路径见 `evidence/ptcgdap/game_modal_ui_20260928.json`。

新增 `GameModalDialog` suite 包括真实 Viewport 的鼠标／触摸分发、重复打开关闭、合成鼠标防穿透、焦点恢复、键盘避让、方向变化、Android 返回及场景控件重挂接。该 suite 7/7 通过，没有脚本错误或资源泄漏诊断。

`scripts/tools/capture_game_modals.gd` 对八类弹窗生成 1360×860、390×844、844×390 共 24 张截图并人工检查。截图位于 `.godot_test_user/modal_review/`。修正了窄屏讨论内容截断、卡组网格右侧溢出、分析表单横向滚动及重命名留白过多的问题。

测试中 D 盘触发既有 2 GiB 余量保护，后续隔离测试改在 C 盘临时目录进行，未降低保护阈值。若需复验：

```powershell
.\scripts\tools\run_godot_tests.ps1 -Runner focused -SuiteScript res://tests/test_game_modal_dialog.gd -ReportDirectory <新的测试输出目录>
```

本次是 Windows Godot 运行、不同尺寸渲染与模拟输入验证，未声明 Android／iOS 真机或浏览器发行包验收。部分既有广泛 UI suite 和截图工具在退出时仍有 ObjectDB／RID 资源警告，因此不声明全项目资源生命周期干净。也不涉及 CABT 合同、引擎一致性或 A5 推广。

## 回滚

仅回退本次 `GameModalDialog` 接入、对应场景类型及相关测试修改，并移除新增组件／截图工具。受影响文件中已有其他未提交工作，不能对整个文件执行恢复来回滚此任务；应按本次弹窗改动逐段恢复。卡组数据、已有导入日期、策略包、规则引擎和私有服务不属于此变更。
