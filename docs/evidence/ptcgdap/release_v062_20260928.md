## 慢测试与失败调查

对长时间未推进的流程检查进程、输出及等待条件，修复过时的 3D 浏览器夹具（浏览器正式版应走 2D）、异步启动等待、导出子进程管道以及缺失本地 HTTP 夹具。未靠无限延长超时换取通过。Python 全套约 12 分钟，逐项持续推进；Windows Python 3.13 的诊断栈转储触发宿主异常，最终全套关闭该诊断插件后正常结束，测试断言保持有效。

Android 第一次最终包复验被模拟器的 Google “Checking info…” 系统页面抢占前台。截图确认后退出该系统页面，复验同一个已安装 APK 通过。模拟器使用主机 GPU 的 OpenGL；不把模拟器 ARM64 转译执行等同 ARM 真机推理或 4 KiB/16 KiB 真机验收。

## WebKit 阻塞与平台边界

最小复现仅包含一个不断改变颜色的 ColorRect，无游戏代码。Godot 官方 4.6.1 Web 模板导出，在 Windows Playwright **1.61.1 / WebKit 26.5** 和 **1.58.2 / WebKit 26.0** 均出现：

```text
WebGL: INVALID_OPERATION: glBlitFramebuffer: Read and write color attachments cannot be the same image.
```

横竖切换后截图变成纯黑。四个游戏 WebKit 项目的新增像素断言也失败。纯手写 WebGL FBO 的对照不复现，定位范围为这台 Windows 上 Godot Web 输出与 WebKit 绘制的组合；不能据此断言真实 Safari 一定失败或一定成功。已尝试不同测试工具版本和渲染诊断，未保留未经验证的生产补丁。

最小复现源码、两版本结果和截图存于 `evidence/ptcgdap/release_v062_20260928/webkit-canary/`。**全平台发布验收仍需 Mac/iPhone/iPad 上的旋转和绘制检查。** macOS ZIP 已校验结构、版本和双架构，但未在 Mac 上运行、验证签名或完成公证；Linux 原生与 iOS IPA 没有生成。Windows/Android 更新程序实验不代表公网更新端点已经上线。
