# 测试架构重构与回归证据

日期：2026-09-22。基准提交：`53cc7f86cb2048827ae29dc510494ded92ceb48c`。
验证对象为包含用户已有修改的当前工作区；本次没有提交或发布。

## 实施结果

统一发现 686 个 Godot 套件，主分类为 UI 93、功能 244、AI 349。
新增自动发现的套件无需再加入旧运行器的硬编码列表；保留旧入口和 `ai_training` 别名。
引擎版本、AI 版本和桌面/触屏/Web 配置通过同一入口选择。

普通回归逐套件隔离进程和用户数据，保存逐项 JSON 和日志。临时用户数据在所属
进程结束后释放，显式指定的测试数据目录保留。加入磁盘余量检查、超时终止、
报告原子写入、续跑和保留原始尝试的合并工具。

以下情形不再产生成功结果：忽略断言返回值、脚本运行错误、启动自动加载错误、
空选择、错误分类/套件、重复注册、无匹配方法、非字符串结果、必填方法参数、
缺失或不一致报告、超时，以及缺少外部环境却静默返回空字符串。

## 回归发现与修复

| 问题 | 修复与验证 |
| --- | --- |
| 滚动后的全局防误触时间戳影响其他页面的按钮 | 状态归属输入页面；定向测试先复现新页面点击被吞，再验证原页面防误触和新页面立即响应。完整 UI 再回归。 |
| 卡牌审核不支持来源/目标分配，误报女服务生出牌失败 | 审核按新交互构造分配，遵守可选来源、排除目标、单目标和目标容量；实际经过出牌入口验证能量附着与训练家弃置。相关 45 项通过。 |
| Web 测试在弹窗排版前点击临时坐标 | 原始轨迹显示关闭操作点在左上角；等待实际布局坐标稳定后只发一次点击，并检查连续三次开关详情。完整六配置浏览器回归无失败。 |
| 编码审核将合法稀有度星号和文档符号当成乱码 | 检查损坏字符、非法标量和控制字符，允许合法多语言与符号；保留替换字符、NUL、代理项和非字符的负向测试。 |
| 合成三帧回放仍套用旧 156 帧录像断言，部分用例依赖本机历史文件 | 合成样本负责布局和完整读写；真实整局现场生成，播放器逐帧比较公开棋盘、公开卡牌和区域计数，验证不修改源数据且无引擎调用权限。 |
| 浏览器进程退出 0 掩盖缺少样本的跳过 | 校验 Playwright JSON，区分通过、失败、缺少先决条件和明确不适用；跳过不计入通过数。 |

## 证据边界与回滚

源码检查保留为审核项目，独立 SceneTree 探针单列，不计入已运行用例数量。
卡牌目录的默认场景烟测不代表穷尽每张卡的全部规则条件；具体卡效仍由功能套件验证。
布局模拟不等于 Android/iOS/macOS 真机验收；WebKit 模拟也不构成真实 Safari 设备证据。
在线服务、已安装历史和固定策略样本缺失均明确记录，没有使用服务凭据补齐测试。

本次达成测试发现、分类、执行和结果证据的一致性整合，并回归已有公开决策与本地
运行门禁；不构成新的 CABT 引擎等价、策略胜率晋级或生产信任批准。

回滚只撤销本次框架、测试工具、回归用例和页面防误触状态归属的修改。对原本已有
改动的文件应按本次差异回退，保留用户已有卡牌、牌组、更新、模型和导出修改。
原始失败报告保留；最终报告以最后一次完整套件复查替换统计，不累加重跑数量。

复现入口及结果语义见 `docs/ptcgdap/testing-architecture.md`。
