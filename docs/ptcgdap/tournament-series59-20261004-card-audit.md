## 获取与复核方式

公共来源为站点 API `/api/v3/tournament/list`、`/api/v3/tournament/rank-individual`、`/api/v3/deck/detail` 和 `/api/v3/card/card-detail`。按精确 `setCode + cardIndex` 对齐印刷，再分别检查实际数据库加载、特性注册、逐招式注册及交互参数。源卡图为真实 PNG，原始缓存保留；发行资源按现有客户端要求转换为无损 WebP，并核对解码后的像素完全一致。JSON 中 source image 哈希指原始 PNG，不是发行文件哈希；未扩展来源牌表到副印刷。

完整可复算的公开卡牌身份、原始规则响应 SHA-256、卡图 SHA-256、逐赛事缺卡及牌表 ID 保存在[同名 JSON 证据](tournament-series59-20261004-card-audit.json)。牌表 ID 可在对应赛事详情页定位。本表不包含玩家账号或任何私有服务发布资料。
