# PTCG Deck Agent 0.6.0

## 本次更新

- 导入 30 周年补充包的全部卡牌，扩充组牌和练牌内容。
- 玩家可以在 AI 策略中心发现 AI 天梯上的开发者策略，一键下载安装，并使用自己的卡组挑战策略 AI；已安装的策略可直接进入对战。
